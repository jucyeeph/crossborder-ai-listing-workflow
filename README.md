# Crossborder AI Listing Workflow (跨境电商 AI 产品自动上架工作流)

## 项目简介
开发一套跨境电商 AI 产品自动上架工作流。用户提供 1688 产品链接或产品图片压缩包后，系统最终输出适合菲律宾市场的产品信息、图片 URL、定价结果，以及可导入 BigSeller ERP 的创建产品表格。

本项目旨在通过 AI 完成 80%～95% 的重复劳动（包括资料采集、信息补充、图片处理、定价计算、表格生成等），保留人工负责最终判断、抽查和发布，而非完全的无人值守。

## 项目愿景与适用场景
- **主要市场**: 菲律宾电商市场（Shopee PH, TikTok Shop PH, Lazada PH等）
- **主要品类**: 美甲产品、甲油胶、猫眼胶、功能胶、美甲工具、套装类产品等标准化程度较高的小商品
- **输入来源**: 1688 产品链接 或 产品图片压缩包 + 少量补充信息

## 核心子工作流
1. **产品资料采集工作流**: 把用户提供的 1688 链接或图片包，转换成统一的产品原始资料。
2. **产品信息补充优化工作流**: 把原始产品信息改造成适合菲律宾电商平台的英文产品资料。
3. **电商图片生成与图床上传工作流**: 生成适合菲律宾市场的电商图片，并上传到稳定图床，返回可用于 ERP 的图片 URL。
4. **产品定价工作流**: 根据供应商成本、汇率、平台成本、物流成本、利润要求，生成适合菲律宾市场的定价建议。
5. **BigSeller ERP 模板化上传工作流**: 将前面生成的产品信息、图片 URL、价格、SKU 等内容填入模板，生成可直接导入 ERP 的表格。

## 第一阶段 MVP 目标
- 品类：美甲单品
- 平台：Shopee PH
- ERP：BigSeller 创建产品模板
- 输入：一个 1688 产品链接或一组产品图片
- 输出：可复核的 Markdown 报告、中间 JSON 文件、可导入的 Excel 表格
