# 项目方向指引

## 目标
建立一套标准化的跨境电商产品自动上架流水线，以 BigSeller ERP 模板为最终出口，标准 JSON 数据为中间层，脚本保证稳定性，AI 完成产品理解和本地化优化。

## 核心原则
1. **不要一开始做 ERP 自动登录和自动点击发布**
2. **第一阶段只做模板化表格输出**
3. **所有子工作流必须有明确输入、输出、中间文件和校验规则**
4. **AI 负责理解和生成，脚本负责确定性处理**
5. **不要把所有功能写成一个大脚本**
6. **先创建项目结构和文档，不要急着实现所有功能**
7. **所有输出格式必须可测试、可复核、可扩展**

## 总体架构分层
1. 用户输入层
2. 资料解析层
3. AI 处理层
4. 确定性生成层
5. 人工复核 / ERP 导入层
