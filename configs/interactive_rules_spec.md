# 交互规则与命名规范

本文档定义了产品信息优化过程中的交互确认流程和字段命名规范。在执行优化工作流时，系统必须按照以下规则与用户进行交互。

## 1. 标题命名规范

- **品牌前缀**：必须以 `JUCYEE` 开头。
- **字数限制**：总字数限制在 100 个字符以内。
- **内容要求**：包含符合电商引流的关键词（如品类、特性等）。

## 2. SKU 交互确认流程

系统在处理 SKU 时，需要先给出推荐，然后等待用户确认或修改。交互格式如下：

```text
parentSKU：[推荐的 parent_sku，例如 JB0213] 推荐_____
产品SKU规则：[推荐的规则示例，例如 JB0213-Star touch 01是01色号] 推荐_____
变种命名规则：[推荐的规则示例，例如 WaveBottle ST #01是01色号] 推荐_____
```

- **用户操作**：如果用户不同意推荐，可以用自然语言进行修改（例如："parentSKU：JB0213推荐JB开头加4位数字"）。
- **变种选项限制**：不能出现中文字，必须用英文，字数限制在 20 个字符以内。

## 3. 定价交互确认流程

系统在处理定价时，需要向用户询问采购价，并根据实时汇率计算出推荐折扣价，等待用户确认。交互格式如下：

```text
采购价：_____ (等待用户输入，单位：人民币)
当前汇率：实时获取 CNY→PHP，加 0.5 浮动缓冲后凑整（如实时 8.93 → 使用 9.5）
```

**计算逻辑**：

1. **汇率** = 实时 CNY→PHP 汇率 + 0.5 浮动缓冲，向上凑整到 0.5 的倍数
2. **推荐折扣价** = 采购价 × 汇率 × 2.5，个位数凑成 9
3. **最终售价（价格\*）** = 推荐折扣价 × 2，个位数凑成 9
4. **活动价** = 推荐折扣价（即 Shopee 折扣活动展示价）

**示例**（采购价 ¥5.80，实时汇率 8.93）：

```text
汇率 = 8.93 + 0.5 → 凑整 → 9.5
折扣价 = 5.80 × 9.5 × 2.5 = 137.75 → 凑整 → 139 PHP
价格* = 139 × 2 = 278 → 凑整 → 279 PHP
活动价 = 139 PHP
```

*注：折扣价是 Shopee 活动展示价（促销价），价格\*（划线价）是折扣价的 2 倍，体现折扣感。用户确认折扣价后将生成最终的 `product.pricing.json`。*
