# 子工作流 2：产品信息补充优化工作流（交互式版本）

## 目标

把原始产品信息改造成适合菲律宾电商平台的英文产品资料，并通过交互式确认流程确保关键字段（SKU、标题、变种、定价）符合品牌规范。

## 输入

- `product.raw.json`
- `raw_images/`（可选）
- 用户补充要求（可选）

## 输出

- `product.optimized.json`
- `product.pricing.json`（定价确认后生成）
- `product_copywriting.md`
- `warnings.md`（如有问题）

---

## 交互式确认流程（必须按顺序执行）

### Step 1：标题生成与确认

系统根据产品原始信息生成英文标题，规则如下：

- **品牌前缀**：必须以 `JUCYEE` 开头
- **字数限制**：总字符数 ≤ 100
- **内容要求**：包含电商引流关键词（品类、特性、用途等）

**示例输出格式**：
```
产品名称推荐：JUCYEE Cat Eye Gel Nail Polish 15ml Galaxy Series UV LED Soak Off Long Lasting Professional Nail Art Color Gel
字符数：98 ✅
请确认或修改：
```

---

### Step 2：SKU 命名规则确认

系统根据产品信息推荐 SKU 命名规则，用户确认后批量生成所有 SKU。

**交互格式**：
```
parentSKU：[产品代码] 推荐_____
产品SKU规则：[示例：JB0213-Star touch 01 是01色号] 推荐_____
变种命名规则：[示例：WaveBottle ST #01 是01色号] 推荐_____
```

**规则约束**：
- 变种选项（variant_value）必须为英文，字符数 ≤ 20
- 不允许出现中文字符

**用户操作**：
- 直接接受推荐（回复"确认"或"OK"）
- 或用自然语言修改（例如："parentSKU：JB0213推荐JB开头加4位数字"）
- Agent 将以用户的规则类推填充所有 SKU

---

### Step 3：产品描述生成

系统自动将产品特征内容嵌入品牌标准描述模板（`configs/product_description_template.md`）：

- **前缀**：品牌标准前缀（固定，不可修改）
- **动态内容**：AI 根据产品信息生成的特征、规格、使用方法
- **后缀**：品牌标准 hashtag 后缀（固定，不可修改）

---

### Step 4：定价交互确认

系统询问采购价，并自动计算推荐折扣价。

**交互格式**：
```
采购价：_____ (请输入人民币采购价，例如：7.20)
```

**计算逻辑**：
1. 推荐折扣价 = 采购价 × 菲币换人民币汇率 × 2.5
2. 尾数处理：个位数凑成 9（例如：91 → 99）
3. 最终售价（价格*）= 推荐折扣价 ÷ 2

**示例**：
```
采购价：7.20 元
当前汇率：1 RMB ≈ 8.2 PHP（可更新）
推荐折扣价：7.20 × 8.2 × 2.5 = 147.6 → 凑整 → 149 PHP
最终售价（价格*）：149 ÷ 2 = 74.5 → 79 PHP

请确认或修改折扣价：
```
